MathQA is the dataset of math word problems and an interpretable neural math problem solver that learns to map problems to operation programs.

MathQA-Python problems are translated from MathQA problems into Python Programming Language.

The dataset is created by running code from https://github.com/google/trax

Paper: https://arxiv.org/pdf/1905.13319
